A project mainly inspired by games like <em>Stellaris</em>, <em>Manor Lords</em>.
At its core it is meant to be a simple simulation of a society with different needs, social classes and happiness.
With different races, wealthiness levels and belligerence, individuals create different social classes that have different global relationships.
In final version, user will be playing the role of a king, with ability to change laws, desirability of jobs, prices and etc, that dirrectly affect the citizens.
